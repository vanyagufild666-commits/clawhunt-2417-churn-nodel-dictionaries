# 行业分类标签字典（对齐国民经济行业分类）

> 工单 S1-DD-017（平台任务编号 2947）· 交付版本 v1.0 · 2026-11-12
>
> 用途：会员企业行业打标与统计；以 GB/T 4754-2017 为参照裁剪，3 级层级、102 个标签，附 JSON 与「无法归类」处理规则。
> 全部为虚构测试数据：企业示例均为虚构名称（带「（虚构）」标记），不对应任何真实企业。

## 三、验收标准对照

1. **标签数量在 80–120 之间，层级不超过 3 级** — 102 个标签（方向 7 / 大类组 23 / 中类叶子 72），层级 3 级 ✅
2. **每个标签都写明对应的国标代码** — 102/102 均有国标代码（门类字母 / 大类两位码 / 中类三位码）✅
3. **JSON 文件能被解析，上级编码都存在** — `行业分类标签字典.json` 102 条可解析；脚本断言 0 悬空上级（1 级上级为 null）✅

## 四、交付物与对接点

| 文件 | 说明 |
|------|------|
| `行业分类标签字典.xlsx` | 2 sheet：字典（102 行×8 列）/ 使用与无法归类规则 |
| `行业分类标签字典.json` | 结构化数据（编码/名称/上级编码/层级/国标代码/判定口径/虚构示例数组） |
| `content.json` + `make_content.py` | 数据源与再生成脚本（含唯一性/悬空/数量断言） |

- 企业档案（2875）`industry_tags` 只挂 3 级叶子，1–5 个；上级方向自动继承用于统计。
- 国标代码保持 GB/T 4754-2017 原位，平台归组（如医疗器械制造归「先进制造」）只影响展示不影响代码。
- 无法归类：置「待归类」标记，运营月度复盘；新业态申请新增叶子走版本化发布，编码不复用。
